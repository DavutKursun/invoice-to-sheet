# Synthetic invoice dataset

Generated by `python scripts/make_synthetic.py --n 80 --seed 7` — 80 fictional invoices/receipts
from 8 fictional vendors, 6 visual templates (fonts, column orders, totals at top/bottom, a narrow
receipt layout), currencies USD/EUR/GBP/TRY with their decimal separators, 1–8 line items, some
discounts. `labels.jsonl` holds the exact ground truth per document.

| kind | files | what |
|---|---|---|
| clean | `pdf/*.pdf` | rendered PDF as a program would export it |
| photo | `photo/*.jpg` | the PDF rendered to an image, then rotated ±3°, blurred, contrast-reduced and JPEG-compressed |
| adversarial | `pdf/*.pdf` | 3 documents with injected instructions in the footer ("ignore previous instructions…") |

Split: 60 dev (tuning), 20 test (run once at the end). Everything is fictional; no real company or
person is referenced. Fonts: DejaVu (see `assets/fonts/LICENSE.txt`).
